Design Decisions

  • Legend container: changed from flex-wrap: nowrap to flex-wrap: wrap — chips reflow to the next row automatically when horizontal space is exhausted. No JavaScript required.
  • Legend chip text: changed from white-space: nowrap; overflow: hidden; text-overflow: ellipsis to white-space: normal; max-width: 140px so full labels remain readable inside the chip per Chaahat Arora's comment.
  • Widget title: removed fixed single-line height cap and added overflow-wrap: break-word so count box titles wrap to a second line rather than clipping when the container is narrow.
  • Date range: collapsed to a calendar icon button (annotated as BisButton / Icon / Ghost). Expanded state is represented as a static annotation "[popover: date range string]" — no live popover at Level 1.
  • No colours, spacing tokens, or typography tokens applied — those are reserved for Level 2 Styled Mockup.

Open Questions

  • Should a wrapping chip maintain a fixed single-line pill height, or is a taller multi-line pill acceptable? A tall pill may look visually heavy against current chip styling.
  • Is there a maximum number of legend rows (e.g. 3) before a "Show more / Show less" toggle is needed, or should all rows always be fully expanded?
