Screen 1 — Teams Landing. Unified search bar replaces separate Verification search. Scanner removed from this page. User cards show compliance status dot + mini progress bar so admins can triage without tapping in. Location cards show aggregate compliance %. Try tapping a user or switching to the Locations tab.
Screen 2 — Unified User Profile. All paths (search, scan, browse) land here. Information hierarchy is flipped: Not Completed shows first and most prominently. Compliance badge gives an instant verdict. Completed section is collapsed by default. Training topics from web are now surfaced in mobile.
Screen 3 — Location Overview (v3). Two tabs only — Attendance is hidden until later. Competence: one card per training form. Main # is total users assigned, with Completed / In Progress / Incomplete breakdown beneath. Compliance: single merged list — compliance-flagged forms (set via a new toggle in form settings on web) show incomplete as the headline; asset forms (auto-assigned by frequency) show in progress as the headline and carry a purple Asset tag identifying the source asset. Locations list is simplified to name + competency % + compliance %.
