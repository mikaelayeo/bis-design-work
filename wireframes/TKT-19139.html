Design Notes

TKT-19139 · Reporter: Luke Koop · Dev: Jithin Joy

Recommendation

Control type

A radio group is the right control here. The choice between Percentage and Raw Numbers is mutually exclusive — only one display mode can be active at a time. A toggle switch implies on/off rather than a choice between two named options, which is ambiguous. A radio group makes both options visible simultaneously and labels them clearly.


Placement

"Display Format" lives in a new Additional Options section, not inside the existing Filter Options multi-select list. Filter Options is an additive list of boolean filters (e.g. Sublocation Data). Display Format is a render-mode selector — it changes how the output looks, not what data is included. Mixing them would be conceptually misleading.

Design Decision

Radio group over toggle. Dedicated "Additional Options" block over embedding in Filter Options. "Percentage" is pre-selected as the default to preserve current behavior for all existing users.

Open Questions

  • 1. Number format string: Should raw numbers render as "10 / 40", "10 out of 40", or "10 of 40" in the actual Excel cells? Mockup uses "10 / 40" for column density; the radio label uses "10 out of 40" for readability.
  • 2. Persistence: Should the Display Format selection persist as a saved per-user preference, or reset to Percentage on each new session?
  • 3. Scheduled reports: Does this setting apply only to on-demand Excel downloads, or also to scheduled report deliveries? If scheduled, does the saved schedule store the format preference?
