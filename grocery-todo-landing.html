Wireframe Notes — Grocery To-Do List (DRAFT / 2026-04-23)

Design Decisions

  • List rows use Table List Item (key: d38774e34a38fcb29a1ceb160080b9a1897fc221) from BIStrainer_UI/Library&Guide. This is the closest BIS native component for a labelled row with leading + trailing actions. Alternatively consider Dropdown List Item (key: 87b6d97c9962446363df673e314b331db6eb20d5) if the designer prefers a denser variant.
  • Checkbox uses BIS Checkbox component set (key: 7568a91ef5dea12364fb7944ad7beda37bbd0e83, updated 2026-04-10). Checked state maps to color/surface/primary. Avoid ARCHIVE-Checkbox+Text (key: 94707eb7c0dff57e26ce595ee5372cff28d5cbbf).
  • Delete action uses BIS Trash icon component set (key: 9f3f6a87b3818484f5e8a9d170ef470bd362b47a). Hover state should use color/icon/error + color/surface/error background.
  • Primary button ("Add Item") uses BisButton (key: d4c9f1f3cc8443d5e9bfa462259949b0436c26da). "Clear Completed" uses the same component at a secondary/ghost variant.
  • Filter chips (All / Active / Completed) map to BisSegementedButtons or Segemented Pills from BIS Web library. Component key not confirmed in search — designer to locate.
  • Item count badge in header uses Tool-Number (key: 33fa7526121f49463ed32bb5b1887dfcaa023ed5).
  • Card container maps conceptually to Banner Card/Default (key: 5e4285438a54ff50801403ed48042844c5f3625b), using border radius/large + color/surface/default.
  • Category tags (Produce, Dairy, etc.) are not in scope per the ticket description but are included as a low-cost affordance. Designer / PM to decide if categories should be a Phase 1 feature.
