Structure

Anatomy

A chip has a container with optional leading icon, label text, and optional trailing dismiss icon. Not all parts are required — the label is the only mandatory element.

1
Leading Icon

Optional. Used in selectable chips to show a checkmark when selected. 14×10px icon.

2
Label

Required. 14px SemiBold Segoe UI. Keep to 1–2 words. Colored to match chip's semantic color.

3
Dismiss Icon

Optional. Present on Dismissible chips only. 10×10px ×. Clicking immediately removes the chip.

Variants

Chip Types

There are two functional chip types — Dismissible and Selectable — plus two shape variants (Box and Circular) and two sizes (Regular and Small).

Guidance

When to Use

Chips are designed for high-density, interactive labeling scenarios. Use them when users need to see, apply, or remove discrete items without navigating away.

✅ Use Chips When

  • Information is short and categorical
  • Multiple items must be visible simultaneously
  • Quick selection or removal is important
  • Displaying active filters or applied tags
  • Multi-select options in a compact space (2–10 items)

❌ Avoid Chips When

  • Labels are long (more than 2–3 words)
  • Hierarchy or deep navigation is required
  • Actions are high-risk or complex
  • There are more than ~10 options (use dropdown)
  • The element is purely informational (use Badge instead)

WCAG Compliance

Accessibility

Chips are interactive elements and must meet WCAG 2.1 AA keyboard and screen reader requirements.

Selectable Chips

Use role="checkbox" with aria-checked for toggle state. Group chips in a role="group" with an accessible label.

Dismissible Chips

The dismiss button must have aria-label="Remove [chip label]". The chip container itself is not focusable unless the entire chip is clickable.

Keyboard Navigation

Enter / Space toggles selection or triggers dismiss. Tab moves to next focusable element. Dismiss buttons within a chip group should be reachable with Tab.

Focus Styling

All interactive chips must have a visible focus outline. Minimum 3:1 contrast ratio for focus indicator against background. Use a 2px offset outline in the primary color.

Color Alone

Never rely on chip color alone to convey meaning. The checkmark icon in the selected state and the × icon in dismissible chips provide non-color indicators of state.

Contrast

Yellow chip text (#a1851f on #feffff) passes AA (5.3:1). All other colors exceed 4.5:1 on white backgrounds. Verify against actual background in implementation.

TypeScript Interface

TypeScript
type ChipColour = "Primary" | "Secondary" | "Green" | "Yellow" | "Red";
type ChipSize = "regular" | "small";
type ChipShape = "box" | "circular";
type ChipState = "default" | "selected";
type ChipType = "selectable" | "dismissible";

interface BisChipProps {
  label: string;           // required
  colour?: ChipColour;    // default: "Primary"
  size?: ChipSize;        // default: "regular"
  shape?: ChipShape;      // default: "box"
  state?: ChipState;      // default: "default"
  type?: ChipType;        // default: "selectable"
  leadingIcon?: boolean;  // default: false
  trailingDismiss?: boolean; // default: false
  disabled?: boolean;    // default: false
  onDismiss?: () => void;
  onSelect?: (selected: boolean) => void;
  className?: string;
}

Selectable Chip Group

React / TSX
// Multi-select filter chips
const [selected, setSelected] = useState<string[]>([]);

const toggleChip = (value: string) => {
  setSelected(prev =>
    prev.includes(value) ? prev.filter(v => v !== value) : [...prev, value]
  );
};

<div role="group" aria-label="Filter by status">
  {["Active", "Pending", "Expired"].map(label => (
    <BisChip
      key={label}
      label={label}
      colour="Primary"
      type="selectable"
      state={selected.includes(label) ? "selected" : "default"}
      leadingIcon={selected.includes(label)}
      onSelect={() => toggleChip(label)}
    />
  ))}
</div>

Dismissible Filter Tags

React / TSX
// Active filter tags that can be removed
const [filters, setFilters] = useState([
  { id: "1", label: "John Smith", colour: "Primary" },
  { id: "2", label: "Reports", colour: "Green" },
]);

<div style={{display: "flex", gap: "6px", flexWrap: "wrap"}}>
  {filters.map(f => (
    <BisChip
      key={f.id}
      label={f.label}
      colour={f.colour}
      type="dismissible"
      trailingDismiss={true}
      onDismiss={() => setFilters(prev => prev.filter(x => x.id !== f.id))}
    />
  ))}
</div>
