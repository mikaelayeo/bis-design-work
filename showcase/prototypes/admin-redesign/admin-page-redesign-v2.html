v2 changes FILL-TO-WIDTH · RESPONSIVE · A11Y
Same tokens as the shipped build, three changes: (1) Fill-to-width grid — replaces fixed 156px + justify-content:start (which left the dead gap on the right) with repeat(auto-fit, minmax(156px, 190px)) + aspect-ratio: cards grow a few px to fill the row, capped so sparse rows like Global don't balloon. Microsoft "All apps" pattern. (2) Favourites & star — empty Favourites collapses to a slim one-line prompt (no padded box); the pin star is now always visible (faint grey at rest, gold when pinned). (3) Responsive + a11y — header search/nav shrink-and-scroll, fluid body padding, 2-up phone grid; skip link, aria-pressed star, live-region announcements, reduced-motion support.
Maps to the live React build: this mirrors v1/views/bisadmin/src/components/subTabs/ (Content.js + subtabs.less). The grid fix is a one-line .less change; drag-reorder already ships via react-sortable-hoc (backed by tblAdminModuleFavourites.fldSortOrder). Icons are Font Awesome stand-ins for the BIS brand SVGs. Touch note: drag here is native HTML5 (mouse + keyboard); the live build's touch reorder is handled by react-sortable-hoc.
