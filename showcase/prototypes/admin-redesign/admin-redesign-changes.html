What changed — property by property

PropertyOld (live)New (redesign)Why / note
Card size ~151px wide · min-height:140px (grows) 156 × 135px fixed Smaller, fixed height → tidier, predictable grid rows.
Icon size ~60–70px fa-5x 45px Reduced so icon + label read as one balanced group.
Icon ↔ label gap incidental (no token) 12px = spacing/base Tokenised — uses the base spacing variable.
Content alignment top-aligned, icon high icon + label centered as one group (natural label height) Each card reads as visually centered. A two-line name grows the group taller within the fixed 135px card (no clipping). Trade-off: a two-line card's icon sits a few px higher than a one-line card's, so icons aren't ruler-aligned across the row — matches the Google-console pattern (title sits under the icon, row isn't baseline-locked).
Label colour matches each module's icon colour — varies card to card (e.g. red label under the red icon) one blue #0078b3 for every card · semibold Standardises labels to a single blue link colour instead of per-icon colours — consistent and clearly actionable.
Label type 14px / 21px · regular 14px / 18px · 600 label/small token.
Border 1px #d8dce3 1px #b2b2b3 = stroke/default Tokenised stroke colour.
Corner radius 10px 8px = radius/medium Tokenised.
Star / favourite grey outline · reveals on hover · top corner · no selected state reveals on hover (same) · gold filled + persists when favourited Adds a clear selected state. Click pins the module into Favourites.
Favourite behaviour Move: starring removes the item from its module list and shows it in Favourites Move — unchanged from live Kept as-is: starring moves the module up into Favourites and the list closes the gap; un-starring returns it to its list. The star shows gold while the module is pinned.
Hover state soft shadow 0 2px 8px rgba(0,0,0,.06) · icon darkens · star reveals + border→blue · translateY(-1px) lift · star reveals Keeps the old shadow, adds a stronger branded affordance (blue border + lift).
Clickable area link wraps icon + text entire card is the click target (star is a nested control) Bigger hit area.
Drag handle n/a 2×3 dot handle, Favourites section only Affords reordering pinned favourites.
Grid grid · gap 10px · space-evenly (cards spread across width) auto-fill · fixed 156px columns · gap 12px · left-aligned Fixed card width packed from the left with a constant 12px gap; leftover space sits on the right. Matches the Figma layout.
Favourites section large cream panel more compact · cream #fffcf2 · gold #a1851f border · radius 8px Tighter footprint; same pinned-cards pattern.

Full interactive prototype: admin-page-redesign.html (same folder). Stack of the live page: ColdFusion (.cfm) + Bootstrap utility classes + CSS Grid + Font Awesome Duotone — no JS framework.
