Folder breadcrumbs

A customer asked for breadcrumbs in the Folders module. Here's the recommended pattern and an interactive demo →

Why not just copy Files / Drive / OneDrive?

They do use breadcrumbs — on web/desktop. On mobile they deliberately drop them: a horizontal path doesn't fit a phone, so they use drill-down (title = where you are, back = up one). The one thing back can't do — and the whole point of the request — is jump up several levels at once.

The solution — "Option C" hybrid

A collapsing breadcrumb that keeps the back chevron for up-one and adds multi-level jumping, sized for mobile:

Hidden at rootNo breadcrumb on the Folders tab — only appears once you're inside a folder.
Pinned rootThe anchor stays fixed on the left and never scrolls off, no matter how deep.
CollapsesDeeper than 3 folders → 🗂 › … › last 3. The current folder is always visible.
Tap to jumpAny crumb jumps to that level. The current folder is bold & not tappable.
"…" overflowOpens a sheet listing every level so collapsed folders stay reachable in one tap.

Try it

Use the buttons under the phone to drill in and out. Go 4+ levels deep to see the … collapse, then tap it for the jump sheet.

Built as production React Native components for SafeTapp (Breadcrumb + BreadcrumbOverflowSheet, wrapping the existing MenuModal). Code handed to dev separately. Icons shown here use Font Awesome 6 to match production: folder-tree root, angle-right separators.
