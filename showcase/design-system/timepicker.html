Structure

Anatomy

TimePicker doesn't introduce new UI primitives — it composes the existing Input Field (as the dropdown trigger) and Dropdown List Item (as each menu row).

1
Label

Above the field. Customize via the Input Field's label text property. Default: "Time".

2
Field (Input Field) Updated 07/24

An Input Field instance with dropdown=true. Shows current value or placeholder ("00:00 AM"). The trailing icon is a clock, not a dropdown chevron — it pairs with DatePicker's calendar icon so the two pickers read as a matched set. Override via the trailing prop.

3
Menu (open only)

A floating panel directly under the field. White surface, light border, soft shadow. ~6 visible slots before scroll.

4
Slot (Dropdown List Item)

Each row is a Dropdown List Item instance — three states: inactive, hover, selected.

5
Selected indicator

When a slot is the current value: blue text, light-blue background, trailing checkmark. Comes for free from the selected variant.

6
Scroll

Vertical scrollbar appears when slot count exceeds the menu's visible height (~6 rows × 32px = 200px).

Composition

Component Reuse

TimePicker is intentionally thin — it composes existing components rather than introducing new patterns. Improvements to those components automatically flow through.

Input Field

The closed state IS an instance of Input Field with dropdown=true. All Input Field props (sizes, error/active/disabled states, leading/trailing icons, helper text) are available by overriding the inner instance.

Dropdown List Item

Each menu row is an instance of Dropdown List Item — variants inactive / hover / selected. Selection visuals (blue text, checkmark) come from this component, not TimePicker.

Guidance

When to Use

✅ Use TimePicker When

  • User selects a single time of day
  • The set of valid times is finite (e.g. 15-min increments)
  • You want consistency with other dropdowns in the app
  • A start/end pair is needed — render two TimePickers side-by-side

❌ Avoid TimePicker When

  • Users type any time precisely (use a masked Input Field)
  • You need a time + date in one UI — use DatePicker + TimePicker
  • Duration is what's being captured (use a number + unit input)
  • Time is implicit (now, end of day) — use a relative button instead

WCAG Compliance

Accessibility

TimePicker is a combobox / listbox combo. Follow the WAI-ARIA combobox pattern.

Roles

Field uses role="combobox" with aria-haspopup="listbox" and aria-expanded. Menu uses role="listbox"; each slot role="option".

Keyboard

Down arrow opens the menu and moves to first/next option. Up arrow moves to previous. Home / End jump to first / last. Enter / Space selects. Esc closes the menu without changing value. Type-ahead jumps to matching slots.

Selection

Currently-selected option uses aria-selected="true". The combobox's aria-activedescendant points to the focused option's id.

Labelling

The label above the field must be associated via aria-labelledby or <label for>. Slot text should include "AM"/"PM" — never rely on color or position.

Touch targets

32px slots are below the 44×44 mobile minimum. Increase slot height to 44px on touch surfaces or wrap each slot in a 44px hit-area while keeping the visual at 32.

Color contrast

Selected slot (#0078b3 on #f2fcff) hits 4.6:1 (AA). The checkmark provides a non-color indicator of selection.

Code

Code Examples

Basic time picker

React / TSX
const [time, setTime] = useState("07:00 AM");

<TimePicker
  label="Start time"
  value={time}
  onChange={setTime}
  interval={15}
/>

Time range (Start + End)

React / TSX
const [start, setStart] = useState("09:00 AM");
const [end, setEnd] = useState("05:00 PM");

<div style={{display:"flex", gap:"12px"}}>
  <TimePicker label="Start" value={start} onChange={setStart}/>
  <TimePicker label="End" value={end} onChange={setEnd}/>
</div>

Custom slots (30-min only, business hours)

React / TSX
const businessHours = [
  "9:00 AM", "9:30 AM", "10:00 AM", "10:30 AM",
  "11:00 AM", "11:30 AM", "1:00 PM",  "1:30 PM",
  "2:00 PM",  "2:30 PM",  "3:00 PM",  "3:30 PM"
];

<TimePicker
  label="Appointment"
  value={time}
  onChange={setTime}
  slots={businessHours}
  required
/>
