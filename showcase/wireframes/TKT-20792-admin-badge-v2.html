✦ New: Build with AI

Several modules now let you create content with AI. Look for the ✦ Build with AI tag — start with Online Courses.

1 of 1
What's in this mock: filled “✦ Build with AI” pills on the three AI tiles (Online Courses, Forms, Playbook), an optional one-time pulse, optional tile accent, and a one-time category coachmark (click the button above).
Accessibility: filled pill is white on #6B3FD4 ≈ 5.9:1 contrast (passes WCAG AA). Pulse is gated behind prefers-reduced-motion — it stops automatically for users who request reduced motion. In production the pulse should run once per session, not loop (it loops here only so you can see it).
Consistency: purple is used nowhere else in the grid, so it becomes the learned “= AI” colour across all AI tiles.
