Pop-up rules (apply to every pop-up below)
  • Icon colour: blue while the trial is running, amber once it has ended. Red is only for the countdown banner and the delete confirmation.
  • Footer order: dismiss, then Delete Module if shown, then the primary on the right.
  • Primary button: Confirm only on a second step, after the user already pressed a named button (Add Module, End Trial, Delete Module). A first prompt names the action: + Add Module.
  • Dismiss button: Cancel when it only closes the pop-up. Return only on the locked in-module pop-up, where it takes the admin away from the page.
  • Delete Module appears only while data still exists (the 60 days).
  • The price box (cost per user per month, billable users, added monthly cost, billing note) is identical everywhere it appears.
A. Trial Banner — End Trial / Add Module Changed

Same Banner component and escalating colours. The price sits in the banner text; the full breakdown is in the pop-up.

Applies to every module with a banner today: Forms, Classroom Calendar, LMS, TRMS, Folders, Assets, Rewards, Playbooks and Driver Management. The module name is written out ("Your Forms module..."). Lone Worker has no admin page, so it uses a modal instead (section E).
B. During the Trial — Add Module and End Trial Changed

Both open from the banner, so both are second steps and end in Cancel / Confirm. Both are closeable.

1. Add Module

Add the Forms module

Adding Forms to your account means you'll keep everything you've built during the trial.

Added cost per user, per month$0.27
Billable users today120
Added monthly cost$32.40

Added in the first 10 days of your billing cycle: billed this month. Added after day 10: billing starts next month. All client admins will be emailed when you add this module.

Sample values ($0.27, 120 users). Real price and billable user count come from the portal's billing data.

2. Module added

Forms module added

The Forms module is now active on your account. We've let your other admins know.

3. End Trial

End your Forms trial?

Ending the trial deletes the Forms module and everything you built in it. This can't be undone.

4. Trial ended — lands on the admin page

Forms trial ended

Your Forms module has been deleted along with the forms and data built in it. It now shows as Trial Ended under Other Available Modules.

After ending the trial, the module moves to Other Available Modules with a red "Trial Ended" badge. Deletion does only what an admin can already do by hand; there is no new purge logic.
C. After Expiry, First 60 Days — Locked Changed

When the trial ends, admins are locked out of the module's admin screens. Learners can still use the module and never see these pop-ups. The module's data still exists and is deleted automatically after 60 days. The countdown is a live value that ticks down daily, and an email goes out too in case an admin doesn't log in for a while.
