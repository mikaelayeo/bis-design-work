TKT-18984 — Design Decisions

  • Bottom sheet as source picker — matches SafeTapp's existing modal pattern. Three options: Camera, Gallery, File Picker. Dismiss via Cancel button or drag-down handle.
  • Two layouts — List (for documents/mixed files) and Grid (for image-only). Developer-selectable at integration time per acceptance criteria.
  • Inline status per file — uploading (progress bar + %), done (checkmark), error (warning icon + message + Retry inline).
  • Delete is always available — including during upload; cancels the in-progress upload.
  • Grid "+" slot triggers bottom sheet same as primary button; disappears when max count reached.
  • Permission error surfaced as M-Alert banner above the upload area (open question: delegate to caller or own it internally).
  • No "No Comment" analogue — upload is optional; no forced submission. Consumers control required-field validation.

Figma Component References

  • M-Button (primary, secondary, ghost) — upload trigger, cancel, retry
  • BottomSheet / M-Modal (bottom-anchored) — source picker
  • M-FileItem (list variant) — file row with thumb, meta, progress, actions
  • M-FileItem (grid variant) — square thumbnail with overlay
  • M-ProgressBar — inline upload progress
  • M-Alert (warning) — permission error banner
  • M-IconButton — delete (×) and view (👁) actions per file
  • EmptyState — zero-file state illustration + label

New Components Needed

  • M-FileItem — both list and grid variants likely need creation or significant extension in the design system.
  • M-ProgressBar (inline) — confirm if an inline/compact variant exists.

Open Questions

  • Q1: Should the component own permission error handling (camera, storage), or delegate to the calling screen? (Ticket open question)
  • Q2: Is there a max file count or max total size enforced by the component, or left to the consumer?
  • Q3: Should mixed-type uploads (images + documents) always use the list layout, or can grid handle mixed types with a file-type icon overlay?
  • Q4: Does "retry" re-open the source picker, or automatically re-attempt the failed upload?
  • Q5: Are skeleton/loading placeholder thumbnails needed while images generate previews?
  • Q6: What is the maximum file size limit, and should the error message be generic or show the limit (e.g. "Max 5 MB per file")?
