# Resources

Shared HTML references, reports, documentation, and learnings for the team.

This folder is for polished artifacts worth sharing — not works-in-progress. Each file should stand on its own as something a teammate can open via a public link and understand without context.

## What goes here

- HTML references (component examples, pattern libraries, comparison demos)
- Reports (research findings, audits, retrospectives)
- Documentation (how-tos, process docs, decision records)
- Learnings (write-ups of experiments or new techniques)

## What doesn't

- In-progress wireframes → use `wireframes/` instead
- Personal experiments or rough drafts → use the private `bis-design-lab` repo
